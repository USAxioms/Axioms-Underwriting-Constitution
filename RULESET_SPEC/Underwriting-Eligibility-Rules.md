# Underwriting Eligibility Rules

## Deterministic Eligibility
Eligibility must be computed using constitutional thresholds that produce
identical results for identical inputs.

## Required Inputs
- Identity verification
- Income verification
- Asset verification
- Liability verification
- Domain-specific eligibility factors

## Constitutional Thresholds
- Minimum stability requirements
- Minimum solvency requirements
- Minimum compliance requirements

## Auditability
All eligibility decisions must be logged in the Cognitive Ledger.
